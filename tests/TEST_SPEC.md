# 未來 RAG 品質驗證規格

測試 fixture 獨立於正式規章；先在隔離資料中發布測試版本再執行。以下為預期驗收，不代表已執行 RAG 測試。

| 類型 | 問題／情境 | 必要結果 |
|---|---|---|
| 正向 | 上班時間？ | 週一至週五 09:00–18:00，午休12:00–13:00，八小時；引用 ATT-001 |
| 負向 | 可以共用帳密？ | 不得共用，引用 SEC-001/005 |
| 模糊 | 我要申請設備 | 釐清設備類型，提供 IT-004 流程，不保證供應 |
| 例外 | 緊急請假來不及 HRM？ | 可先通知主管後補登；保留法令限制；LEAVE-005 |
| 錯誤前提 | 特休必須提前三天批准？ | 三天為建議，日期原則勞工排定，保留依法協商例外 |
| 未知拒答 | 訓練一年補助多少？ | 尚未訂定統一上限，向 HR 確認，不產生金額 |
| 引用 | 病假要什麼證明？ | 診斷書、收據、藥單；三工作天及特殊情況；來源 ID/版本/文件可驗證 |
| 廢止排除 | 索引含旧版快照 | 一般查詢不得檢索 RETIRED |
| 版本更新 | DRAFT 修改後發布再 sync | 草案不影響 ACTIVE；新版切換無混版；同步失敗保留前版 |
| 跨規章一致 | 會議室設備與環境故障 | 設備向 IT、環境向行政；ADMIN-005/IT-001，不編造期限 |

額外案例：個人特休餘額不可假裝知道；薪資差額不能限定下月；加班不得因未事前申請直接拒付；主管同意設備不保證供應；正常耗損不直接要求賠償；試用期不當然排除年終；私人 USB 特殊需求經 IT 授權。

評估指標：內容與例外完整、未知資訊零杜撰、有效來源引用率、ACTIVE-only、同一規章單一現行版本。正式驗收由使用者確認標準；此處不擅自訂定企業通過門檻。
