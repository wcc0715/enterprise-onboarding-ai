# ADMIN：行政管理

> 模擬企業內部制度；尚未全部完成法律審查，不代表台灣企業普遍制度。
> 發布狀態與版本以 metadata/regulation_manifest.json 為準；本檔為草案編輯區。

## ADMIN-001 工作證遺失

立即通報行政部門。必要時停用門禁權限。依身分確認程序補發。補發費用及期限尚未訂定。

## ADMIN-002 辦公用品

一般文具可直接向行政部門申請領用。特殊或非庫存用品須先由主管確認需求。

## ADMIN-003 辦公環境

冷氣、照明、辦公桌椅等問題，向行政部門通報。不得自行處理可能涉及安全風險的維修。

## ADMIN-004 訪客管理

外部訪客進入非公開辦公區前須依規定登記。接待員工應事先通知行政部門。訪客進入非公開區域原則上須有公司人員陪同。管制區域不得未經授權進入。離場時須完成登記及歸還訪客證。訪客資料應依個資規範管理。

## ADMIN-005 會議室

員工可透過內部系統自行預約。一般預約不需主管簽核。取消使用時應儘早取消。資訊設備故障通知 IT。環境設施問題通知行政部門。特殊活動或設備需求可由行政部門協助。
