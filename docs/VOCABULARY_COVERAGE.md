# 詞彙覆蓋表

詞彙只用於尋找相關條文，不等於認定問題中的前提正確。以下例句屬測試資料。

| 條文 | 新增常見說法 | 測試問題 |
|---|---|---|
| LEAVE-001 | 私人事情、私事請假、事假申請 | 我有私人事情，事假要提前多久申請？；處理私事請假要怎麼辦？ |
| LEAVE-002 | 假單怎麼填、請假怎麼申請、請假找誰、請假要找誰、請假手續 | 請假手續有哪些？；假單怎麼填？ |
| LEAVE-003 | 頭痛、肚子痛、身體不適、病假證明 | 肚子痛不能上班怎麼辦？；身體不適要交什麼證明？ |
| LEAVE-004 | 特別休假、年假、特休排定 | 特別休假要主管批准嗎？；年假要提前多久說？ |
| LEAVE-005 | 臨時急事、緊急狀況請假、突然有急事 | 突然有急事，可以晚點補假單嗎？；臨時急事無法先登系統怎麼辦？ |
| ATT-001 | 幾點上班、幾點下班、上下班時間、中午休息 | 公司幾點上班？；中午休息多久？ |
| ATT-002 | 忘記刷卡、漏刷卡、沒有打卡、忘了打卡 | 今天沒有打卡怎麼補？；忘記刷卡可以補登嗎？ |
| ATT-003 | 晚到、來不及上班、趕不上上班、上班晚了 | 塞車會晚到，怎麼通知？；今天趕不上上班怎麼辦？ |
| ATT-004 | 超時工作、下班後工作、加班費、換補休 | 下班後工作一定要先申請嗎？；加班費可以換補休嗎？ |
| IT-001 | 電腦當機、無法開機、螢幕黑掉、鍵盤壞了、滑鼠壞了 | 我的螢幕黑掉找誰？；鍵盤壞了不能工作怎麼辦？ |
| IT-002 | 備機、備用機、設備換新、電腦換新 | 修電腦時一定有備機嗎？；設備換新由誰評估？ |
| IT-003 | 裝軟體、下載軟體、自己修電腦、送外面修、拆電腦 | 可以自己修電腦嗎？；工作電腦能送外面修嗎？ |
| IT-004 | 多一個螢幕、第二個螢幕、領新設備、新增設備 | 我想要第二個螢幕怎麼申請？；主管同意新增設備就能領嗎？ |
| IT-005 | 電腦摔壞、設備賠償、正常耗損、螢幕摔壞 | 電腦摔壞要全部賠嗎？；設備正常耗損誰處理？ |
| IT-006 | 筆電帶回家、帶走筆電、電腦帶出去、共用設備借用 | 筆電帶回家每次要申請嗎？；共用設備借用要登記嗎？ |
| SEC-001 | 忘記密碼、重設密碼、帳號密碼、帳密共用 | 忘記密碼該怎麼辦？；帳密共用可以嗎？ |
| SEC-002 | 詐騙信、奇怪郵件、點了可疑連結、可疑附件 | 點了可疑連結要怎麼辦？；收到奇怪郵件可以開附件嗎？ |
| SEC-003 | 隨身碟、私人隨身碟、自己的usb、私人usb | 可以用自己的隨身碟存公司資料嗎？；私人隨身碟有例外嗎？ |
| SEC-004 | chatgpt、ai工具、外部ai、人工智慧工具、把資料貼給ai | 公司資料可以貼給ChatGPT嗎？；使用AI工具要注意什麼？ |
| SEC-005 | 沒有系統權限、開通權限、存取權限、共用帳號 | 我要開通權限找誰？；可以用同事的共用帳號嗎？ |
| SEC-006 | 寄錯人、資料寄錯、誤傳資料、資料外流 | 我把公司資料寄錯人怎麼辦？；發現資料外流要提供什麼資訊？ |
| HR-001 | 薪水幾號、何時領薪、薪資入帳、發薪日 | 每月薪水幾號發？；薪資入帳遇假日怎麼辦？ |
| HR-002 | 薪水少了、薪水算錯、少發薪水、薪資不對 | 我被少發薪水找誰？；薪資不對只能下月補嗎？ |
| HR-003 | 更換薪轉戶、薪轉帳戶、改薪資帳戶、薪轉銀行 | 改薪資帳戶要誰申請？；更換薪轉戶怎麼驗證？ |
| HR-004 | 生日禮、員工活動、到職福利、員工福利 | 到職福利從什麼時候開始？；公司有哪些員工活動福利？ |
| HR-005 | 人事系統、hrm權限、員工資料查詢、查同事資料 | 人事系統能看哪些資料？；可以查同事資料嗎？ |
| HR-006 | 年終、年底獎金、績效獎金、試用期獎金 | 年底獎金有保障嗎？；績效獎金一定有固定金額嗎？ |
| ADMIN-001 | 識別證遺失、門禁卡不見、員工證不見、工作證補發 | 員工證不見了找誰？；門禁卡不見要停用嗎？ |
| ADMIN-002 | 領文具、拿文具、申請文具、買辦公用品 | 我要領文具要主管批准嗎？；買辦公用品遇非庫存品怎麼辦？ |
| ADMIN-003 | 空調壞了、燈不亮、椅子壞了、桌子壞了 | 辦公室空調壞了找誰？；椅子壞了可以自己修嗎？ |
| ADMIN-004 | 客人來訪、外人進公司、訪客證、客戶來訪 | 客戶來訪要先通知誰？；外人進公司辦公區需要陪同嗎？ |
| ADMIN-005 | 訂會議室、借會議室、會議室預訂、會議空間 | 借會議室需要主管簽核嗎？；不用了如何取消會議室預訂？ |
| TRAIN-001 | 新人課程、新人訓練、入職訓練、到職訓練 | 新人課程有哪些必修？；入職訓練每個部門相同嗎？ |
| TRAIN-002 | 錯過訓練、沒參加訓練、訓練缺席、補課方式 | 沒參加訓練怎麼辦？；錯過訓練可以看教材補課嗎？ |
| TRAIN-003 | 進修補助、研習補助、職能訓練、外部培訓 | 職能訓練能不能給補助？；外部培訓完成後需要什麼文件？ |
| TRAIN-004 | 上課紀錄、完訓紀錄、訓練紀錄有誤、課後心得 | 上課紀錄去哪裡查？；訓練紀錄有誤找誰更正？ |
