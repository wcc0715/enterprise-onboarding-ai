# Ollama 意圖理解與生成

本次接入模型意圖解析：先執行資料能力、未知制度、版本及發布狀態檢查，再讓模型解析可處理的問題。傳送目前問題、最近最多六個問題與允許規章的來源編號及標題；不傳送金鑰、完整專案或真實 HRM 資料。

模型輸出限來源 ID、對象（本人／家人／寵物／其他／未知）、請假或其他任務、緊急與建議旗標。候選必須存在於當次模式允許的來源。照顧其他人或寵物不接受本人病假來源；對象未知則先釐清。請假對象解析後交由有來源的受控回覆；一般檢索結果才交模型生成。固定回覆仍會顯示模型意圖解析是否成功，不能把意圖解析成功當作答案由模型生成。

模型仍可能誤判語意或選錯真實來源。來源、格式及數字驗證不能證明生成內容正確；需要實際雲端品質測試。安全與未知回覆不開放模型自行補完，DRAFT 不會成為 ACTIVE。

啟動時進行最小連線測試。錯誤只顯示固定代碼，不輸出金鑰、遠端本文或例外原文：

| 代碼 | 意義 |
| --- | --- |
| AUTH_FAILED | HTTP 401，驗證失敗 |
| ACCESS_DENIED | HTTP 403，存取被拒 |
| MODEL_OR_ENDPOINT_NOT_FOUND | HTTP 404，模型或路由找不到 |
| RATE_LIMITED | HTTP 429，請求受限 |
| CLOUD_HTTP_ERROR | 其他 HTTP 錯誤 |
| NETWORK_ERROR / TIMEOUT | 網路問題或逾時 |
| KEY_MISSING | 未設定後端金鑰 |
| OUTPUT_INVALID | 回傳解析或驗證未通過 |

API 回覆包含 interpretation_status / interpretation_error 與 generation_error。頁面會標示意圖解析、模型生成或回退狀態。啟動中的 app_version 固定為載入程式時的雜湊；修改磁碟程式不會讓舊服務冒充新版，必須重啟。

離線測試使用模擬模型驗證陌生親屬稱謂、追問、無效來源、非本人病假排除及邊界不呼叫模型。真實 Ollama 連線與回答尚待使用者重新啟動後驗證，不能宣稱已成功。
